# Calculadora - Atividade 06

Aplicativo de calculadora desenvolvido em Kotlin utilizando Jetpack Compose.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Porcentagem
- Alteração de sinal (+/-)
- Números decimais
- Limpar (AC)
- Exibição da operação e do resultado

## Tecnologias utilizadas

- Kotlin
- Jetpack Compose
- Android Studio
